# Проверка Ekza Studio на iPad (Pencil и пальцы)

Для релиза v0.7.0 (STUDIO-TOUCH-SPEC §22: AS-ST-1, 11, 12, 13 и список D1–D17). Откройте сборку-кандидат в Safari на
iPad. У каждого пункта: что сделать → что должно произойти. Отметьте «да / нет»; если «нет» — снимок экрана или видео и
одна строка, что случилось. Запишите модель iPad, версию iPadOS и Safari, модель Pencil.

1. Откройте адрес сайта → сразу главная **Ekza Studio**, без окон и вопросов. Справа вверху тихая ссылка «Pro layout».
2. Поверните iPad вертикально и обратно → всё помещается, ничего не обрезано, кнопки у краёв не пропадают.
3. **Try a sample** → появляется робот Polybot, можно сразу работать.
4. Внизу **Library** → **Walk** → **Add**, затем ▶ → робот идёт плавно, без рывков.
5. Пальцем коснитесь руки робота → рядом появляются слова-команды; потяните кисть → рука тянется за пальцем.
6. Коснитесь экрана двумя пальцами → последнее действие отменяется. Щипок двумя пальцами → вид приближается плавно,
   а сама страница не увеличивается (D4, D17).
7. Тремя и четырьмя пальцами коснитесь холста → в студии ничего не происходит (жесты самой iPadOS допустимы) (D10).
8. Долгое нажатие пальцем на робота → кольцо команд; системного меню «Скопировать / Поделиться», лупы или выделения
   текста нет; рисунок не прерывается (D16).
9. **Share ⤴** → **OMOBA & Ekza Space** → кнопка экспорта → в системном окне «Сохранить в Файлы» → файл `.vrm` в
   приложении «Файлы». Всего два касания. Точка «есть несохранённое» у имени проекта остаётся (AS-ST-13, D11).
10. Так же сохраните `.glb` (**Game engine**) и `.vrma` (только анимации) → оба оказались в «Файлах» (D11).
11. Меню проекта (имя слева вверху) → **Save project to Files** → два касания → файл `.ekzanim` в «Файлах» (D11).
12. После первого сохранения появляется карточка «Keep projects on this iPad» → нажмите → запишите, что ответил Safari
    (разрешил или нет) (D12).
13. Новый проект → **Bring a model** → выберите сохранённые `.vrm`, потом `.ekzanim`, потом `.vrma` → каждый открывается
    правильно: персонаж, проект, анимация на персонаже (AS-ST-13, D2).
14. Перетащите модель `.glb` из «Файлов» (окно рядом, Split View) на холст → модель открывается (D9).
15. **Try a sample** › другие образцы › **Cube Lad** → **Rig it for me** → **For: OMOBA** → **Rig it** → через несколько
    секунд «Rigged», куб ходит.
16. **Paint weights**: рисуйте Pencil'ем, нажимая то слабо, то сильно → след слабее и сильнее; быстрый размашистый штрих —
    без пропусков (AS-ST-12, D5).
17. Рисуя Pencil'ем, положите ладонь на экран → ладонь ничего не выделяет и не крутит вид (AS-ST-12, D14).
18. Начните штрих Pencil'ем у самой верхней панели (≈ 5 мм под ней) → это рисунок, а не рукописный ввод текста (D15).
19. Палец на коже персонажа и подержать → карточка «Who owns this?» с костями; тап по кости → рисуется вес этой кости.
20. С клавиатурой Magic Keyboard: коснитесь пальцем полосы времени внизу, затем нажмите пробел → воспроизведение
    (D1). Двухпальцевый клик по тачпаду на роботе → кольцо команд (D3). Щипок на тачпаде → приближение (D4).
21. С тачпадом: Numbers (цифры у выделенной части) → потяните значение вбок → число меняется плавно, курсор не убегает
    за край экрана (D6).
22. **Большая работа (AS-ST-11, D7, D8)**: ваш персонаж около 60 000 треугольников, с костями и 3 анимациями, 30 минут
    обычной работы (позы, ключи, Curves, переключение этапов, экспорт) → вкладка Safari ни разу не перезагрузилась.
    Запишите объём памяти iPad.
23. Перезагрузите страницу посреди работы → тот же проект, этап, кадр, выделение и тот же вид камеры, надпись «Back
    where you were», ни одного касания.
24. **Pro layout** → строка «Studio Pro is laid out for a mouse and keyboard» → **Open anyway** → открывается Pro с тем же
    проектом и надписью «Same project, every panel at once · Undo still works»; кнопка «Simple layout» возвращает назад.
25. «Поделиться» › «На экран Домой», откройте студию с экрана Домой → у неё свои проекты (Continue пуст), а проект,
    сохранённый в «Файлы», открывается через **Bring a model** (D13).
26. Help › About → версия и пометка **Beta**.
27. Включите VoiceOver → верхняя панель, команды рядом с выделением, этапы (Make · Paint · Rig · Animate) и кнопка-модификатор
    внизу читаются понятными словами.

Результаты положите в `docs/evidence/halo/device-run-<дата>.md` (или пришлите агенту) — это закрывает AS-ST-21.
